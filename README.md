# PDF RAG Assistant

A local RAG application for PDF documents. The interface sends questions to a FastAPI backend, which retrieves relevant content from ChromaDB and provides it to Ollama's Qwen3 model for answer generation.

## Technologies

- Next.js 16 and React 19
- TypeScript and CSS Modules
- FastAPI
- LangChain
- ChromaDB
- Hugging Face sentence embeddings
- Ollama and Qwen3

## Project structure

```text
backend/
  app.py       FastAPI server and /chat endpoint
  ingest.py    PDF document loading and indexing
  rag.py       Chroma retrieval and Ollama request
docs/          PDF documents
db/            ChromaDB database
frontend/
  src/app/     Next.js page and layout
  src/components/
               Sidebar, message list, and chat input
  src/styles/  CSS modules
```

## Requirements

- Python 3.10 or newer
- Node.js 20 or newer
- Ollama

The Qwen3 model must be downloaded for Ollama:

```powershell
ollama pull qwen3
```

## Installation

### 1. Python dependencies

Install the dependencies from the project root:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
pip install fastapi uvicorn
```

### 2. Frontend dependencies

```powershell
cd frontend
npm install
cd ..
```

## Indexing PDF documents

Add PDF files to the `docs/` directory and create the vector database:

```powershell
python backend/ingest.py
```

Indexing reads all PDF documents from `docs/`, splits them into chunks, and stores them in `db/`.

## Running the application

Start the backend:

```powershell
cd backend
uvicorn app:app --reload --host 0.0.0.0 --port 8000
```

Start the frontend in a second terminal:

```powershell
cd frontend
npm run dev
```

Open the application at:

```text
http://localhost:3000
```

Check the backend status at:

```text
http://localhost:8000
```

## Development

Build and lint the frontend:

```powershell
cd frontend
npm run build
npm run lint
```

## API

### `POST /chat`

Request:

```json
{
  "question": "What does the document say?"
}
```

Response:

```json
{
  "answer": "The answer generated by the model."
}
```
